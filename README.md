# 幸运彩票站

一个以中国商场彩票店为背景的即开型彩票体验模拟游戏。

玩家以普通逛商场的路人视角进店，先设定预算，再从店里正在销售的开本中选票。彩票要按住硬币来回刮开；看清票面后还不能直接入账，必须交给老板刮开保安区、扫描验奖，才可以兑奖或按同等面值继续换票。

所有资金均为虚拟数值。项目不连接任何真实彩票销售、支付或兑奖服务。

## 当前版本

`v0.6.0`：50 款票库、真实黑色图符、灰底黑字奖面与低密度高奖模型。

- 商场进店、成年确认、预算封顶和离店结算
- 需要持续拖动的逐步刮开，不再点击或碰到就整张揭开
- 玩法区露出后只进入“待验票”，奖金在老板扫码后才入账
- 模拟玩法区、保安区、物流/流水信息的真实票面结构
- 参考官方资料建立 50 个配置，覆盖 10、20、30、50 元
- 新增“66顺88发”“连中三元”“唐风宋韵”“国泰民安”“有福”等真实玩法
- 刮开后统一使用实体票常见的灰底黑字奖面，20 枚黑色印刷图符不再用文字代替
- 普通整本与百元以上奖档分开建模，显著降低 100–1000 元奖档密度
- 当日门店随机上架 14 款，可按票名、玩法与面值筛选
- 金额直出玩法的未中奖位置为空白，奖金只在随机位置出现
- 每个票种按整本预生成结果，同款可同时有 2–4 个已拆开本
- 随机开本进度、缺货与模糊库存状态，玩家看不到精确余量
- 可自己从露出的单张中挑，也可让老板代拿；密封整本需单独询问
- 硬币、小号刮片、宽口刮铲三种效率，中奖位置不额外高亮
- 单张、连买、密封整本和门店自配 100 元惊喜包
- 多组随机老板对白，以及兑奖后“收钱/同价换票”的选择
- 可选逛街剧情模式，把商场事件带入老板对白；不联网、0 Token
- 大模型已完成成本评估，公开版暂不接入，避免泄露密钥或产生无上限费用

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。

验证命令：

```bash
npm run lint
npm test
```

## 真实性边界

- 票价、公开玩法、最高奖、奖级数量、票面结构和未成年人限制优先采用官方资料。
- 每张票在整本生成时就确定结果，购买选择、老板对白和刮票顺序不会临时“控奖”。
- 65% 是发行层面的长期返奖资金比例，不等于每本固定返还 65%。
- 公开资料不足以复原某一真实生产批次的逐本奖项位置；本项目使用可解释的波动模型，不宣称能预测现实彩票。
- 票面是对真实视觉语言的仿真重绘，不包含可用于真实兑奖的条码、完整序列号或安全数据。

完整依据见 [docs/research.md](docs/research.md)。
