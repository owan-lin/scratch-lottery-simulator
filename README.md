# 幸运彩票站

一个以中国商场彩票店为背景的即开型彩票体验模拟游戏。

玩家以普通逛商场的路人视角进入彩票店，先设定预算，再从店内正在销售的整本彩票中选票。中奖后可以兑奖收钱、保留奖金，或按面值继续换票。所有资金均为虚拟数值，游戏不连接任何真实彩票销售或兑奖服务。

## 当前版本

`v0.1.0`：可玩的真实性原型。

- 商场进店、成年确认与预算设定
- 5、10、20、50 元四档原创票面
- 金额直出、数字匹配、符号命中、复合玩法
- 每本彩票在上架时一次性生成，单张购买按流水号顺序取票
- 单张、连买、整本和 100 元店内盲盒
- 奖金直接兑奖或继续换票
- 老板根据预算、中奖和连续未中奖情况进行对话
- 离店小票与本次盈亏统计
- 鼠标、触屏刮开与无障碍“快速刮开”

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。

## 真实性原则

游戏将公开可核验的事实与模拟假设分开：

- 票价、常见玩法、未成年人限制、返奖资金结构来自公开规则。
- 每张票在整本上架时就确定结果，不会根据玩家选择临时“控奖”。
- 官方通常不公布“每一本必有多少奖金”的承诺，因此单本回报会明显波动。
- 概率模型长期期望返奖率约为 65%，单本结果不保证接近该数值。
- 票面名称、版式和美术为原创，不使用官方商标或可兑奖票样。

完整依据见 [docs/research.md](docs/research.md)。
