# 短期版本路线

## v0.1 — 可玩的流程原型

完成逛商场、进店、定预算、选票、刮票、兑奖/换票和离店闭环。

## v0.2 — 慢刮与柜台验票（当前）

- 持续拖动刮开覆盖膜，移除点击即揭票
- 玩法区露出后必须找老板扫描验票
- 四种真实票种原型与金额直出空白底
- 随机缺货、随机开本进度、隐藏精确余量
- 多组随机进店、购买、中奖、劝收手对白
- 公开 GitHub 与无需登录的试玩链接

## v0.3 — 整本数据校准

- 建立可导入的“整本实刮记录”JSON/CSV 格式
- 汇总公开视频的票价、张数、总奖金、中奖张数和最大单票
- 增加固定随机种子与十万本蒙特卡洛测试
- 在研究页展示单本回报分位数，但不泄露当前游戏这一本
- 为真实票种补齐批次级奖级构成表

## v0.4 — 触感与声音

- 基于移动距离与速度生成刮擦声音，不循环播放固定音效
- 刮屑堆积、硬币角度和局部破膜反馈
- 雨天、晚饭前、闭店前等轻量随机事件
- 老板熟客程度与更长的情境对白

## v0.5 — 可选本地对话模型

- 默认仍使用无需账号的离线对白算法
- 可选接入小型语言模型扩展闲聊
- 对话不能改变票面结果、预算或兑奖数据
- 明确费用、隐私与失败回退

## 更新原则

短期保持小版本迭代：每次只改变一组可验证的体验或数据，并在研究文档和更新日志中同步披露。
