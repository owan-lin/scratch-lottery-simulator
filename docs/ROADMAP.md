# 短期版本路线

## v0.1 — 可玩的流程原型

完成逛商场、进店、定预算、选票、刮票、兑奖/换票和离店闭环。

## v0.2 — 慢刮与柜台验票

- 持续拖动刮开覆盖膜，移除点击即揭票
- 玩法区露出后必须找老板扫描验票
- 四种真实票种原型与金额直出空白底
- 随机缺货、随机开本进度、隐藏精确余量
- 多组随机进店、购买、中奖、劝收手对白
- 公开 GitHub 与无需登录的试玩链接

## v0.3 — 柜台选票与刮奖工具

- 同款票同时生成多个开本，展示多个可选的露出票
- 玩家自己挑单张，或让老板代拿 1/3/5 张
- 整本改为独立询问密封库存
- 增加三种宽度不同的刮奖工具
- 去除中奖位置的额外视觉标记

## v0.4 — 30–50 种真实票库

- 数据驱动票库、当日随机上架、价格和玩法筛选
- 官方事实与体验模型分级标注
- 建立可导入的整本实刮记录格式和单本分布摘要
- 增加固定随机种子与大样本模拟测试

## v0.5 — 逛街剧情与 Token 评估

- 默认使用无需账号、零 Token 的本地剧情状态机
- 评估可选小型语言模型的每局 Token 和费用上限
- 对话不能改变票面结果、预算或兑奖数据
- 明确费用、隐私与失败回退

结论：先发布本地剧情状态机；公开版暂不接入大模型。

## v0.6 — 票面图符、低密度高奖与 UI 分支

- 票库扩充至 50 个配置，优先补齐“66顺88发”和“连中三元”
- 奖面统一为灰底黑字，常见吉祥物改用真实印刷图符
- 百元以上奖档从普通填充逻辑中隔离，增加长期概率回归测试
- 保留 3 个常规视觉分支，并额外制作高浓度特效实验分支

## v0.7 — 统一验奖引擎、60 款票与三套高级 UI（当前）

- 所有票种只按可见号码、图符与金额兑奖，生成后立即反算并拒绝不一致票面
- 新增“幸运123”“非常有戏”“采蘑菇”“万事如意”“新芽”与 2026 马年五款票
- 元宝、骏马、祥云等统一使用 SVG 图符；只有玩法明确规定为数字或汉字的奖符保留字形
- 2026 马年五款票按官方完整奖组数量抽样，明确奖组不等于实体单本
- 用逐奖级、空票、整本三层性质测试覆盖 60 款票
- 发布商场微缩柜台、赛博街机、木桌票册三套结构不同的 UI 分支

## 更新原则

短期保持小版本迭代：每次只改变一组可验证的体验或数据，并在研究文档和更新日志中同步披露。
