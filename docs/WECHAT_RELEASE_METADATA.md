# 微信小程序发布资料

## 推荐基础信息

- 名称：`刮卡概率实验室`
- 备用名称：`刮卡手感实验室`、`银层刮卡模拟器`
- 简介：`离线刮卡与概率模拟工具，使用虚拟筹码，不含真实投注、购票、兑奖、预测或现金交易。`
- 图标：`public/assets/miniprogram-icon-512.png`
- 服务对象：18 周岁以上用户
- 网络服务：无；当前版本完全本地运行
- 用户信息：不收集手机号、位置、通讯录、相册或其他个人信息
- 支付与变现：无微信支付、充值、提现、广告或实物兑换

## 审核说明建议

本小程序是概率教育与刮卡交互模拟工具。所有余额、票面和奖金均为本地生成的虚拟数据，不能充值、提现或兑换实物；不销售、代购、推荐或预测任何现实彩票，也不跳转至购彩渠道。当前版本不要求登录，不采集用户信息，不使用服务器。

## 类目与发布边界

应在微信公众平台中选择与实际功能完全匹配、且当前账号可选的服务类目。当前产品具有明显的游戏化交互，同时包含彩票题材；不要通过选择不相关的工具或教育类目规避平台审核。

若平台将其认定为“小游戏”或彩票相关服务，应停止普通小程序提审，先通过平台工单确认所需类目与资质。当前版本可继续作为开发/体验版本供管理员、开发成员和体验成员测试。
